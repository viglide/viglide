# Security Policy

Do not open public issues for security vulnerabilities. Email alexander.oreshkevich@gmail.com
with details and reproduction steps; you will get an acknowledgement within 7 days. Coordinated
disclosure: we ask for up to 90 days to ship a fix before public disclosure. There is currently
no bug bounty (and none is planned — see CONTRIBUTING.md). Never include real exchange API keys
in reports, issues, or code.
